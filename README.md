# Sales-Data-Analysis-Excel

# مشروع تحليل أداء موظفي المبيعات في شركة اتصالات

## نبذة عن المشروع

يهدف هذا المشروع إلى تحليل أداء موظفي مركز الاتصال (Call Center) في شركة اتصالات تقدم خدمات الإنترنت والألياف البصرية (Fiber Internet). تعتمد الشركة على التواصل مع العملاء عبر المكالمات الهاتفية لعرض الباقات والخدمات المختلفة وتحفيز العملاء على الاشتراك.

## أهداف المشروع

* تقييم أداء موظفي المبيعات بناءً على البيانات الفعلية.
* تحديد الموظفين الأعلى تحقيقاً للمبيعات.
* تحليل عدد المكالمات الناجحة والفاشلة لكل موظف.
* قياس معدل تحويل المكالمات إلى عمليات بيع ناجحة.
* تحديد الموظفين الأكثر كفاءة من خلال تحقيق مبيعات مرتفعة بعدد مكالمات أقل.
* دعم الإدارة في اتخاذ القرارات المتعلقة بالمكافآت والتدريب وتحسين الأداء.

## البيانات المستخدمة

تشمل البيانات المعلومات التالية:

* رقم الموظف.
* اسم الموظف.
* عدد المكالمات الصادرة.
* عدد المكالمات الناجحة.
* عدد المكالمات الفاشلة.
* عدد العملاء الذين تم الوصول إليهم.
* عدد الاشتراكات أو المبيعات المحققة.
* قيمة المبيعات الإجمالية.
* تاريخ المكالمة.

## التحليلات المنفذة

1. تحليل إجمالي المبيعات لكل موظف.
2. مقارنة عدد المكالمات الناجحة والفاشلة.
3. حساب نسبة نجاح المكالمات.
4. تحديد أفضل موظف من حيث حجم المبيعات.
5. تحديد أكثر الموظفين كفاءة من خلال تحقيق أعلى مبيعات بأقل عدد من المكالمات.
6. تحليل العلاقة بين عدد المكالمات والمبيعات المحققة.
7. إنشاء لوحة معلومات تفاعلية لمتابعة الأداء.

## الأدوات والتقنيات المستخدمة

Data cleaning, analysis, and dashboard design using Advanced Excel

## النتائج المتوقعة

* معرفة أفضل الموظفين أداءً.
* تحسين استراتيجيات التسويق والمبيعات.
* زيادة معدل تحويل العملاء المحتملين إلى مشتركين فعليين.
* رفع كفاءة فريق المبيعات وتقليل الجهد المبذول في المكالمات غير الفعالة.

## الخاتمة

يساعد هذا المشروع الإدارة على فهم أداء موظفي المبيعات بشكل دقيق من خلال تحليل البيانات واستخراج مؤشرات الأداء الرئيسية، مما يساهم في تحسين الإنتاجية وزيادة الأرباح واتخاذ قرارات مبنية على البيانات.
